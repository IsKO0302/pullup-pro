# Telegram: бот и Mini App

Приложение работает и без Telegram. Telegram добавляет: запуск как Mini App, автоматический вход, синхронизацию между устройствами, команды бота и напоминания.

## Что нужно

- Бот, созданный в [@BotFather](https://t.me/BotFather), и его токен.
- Публичный **HTTPS**-адрес, по которому открывается веб-приложение (`WEBAPP_URL`). Telegram не открывает Mini App по HTTP. Для теста подойдёт любой HTTPS-туннель к локальному API.
- Развёрнутые API и PostgreSQL (см. [DEPLOYMENT.md](DEPLOYMENT.md)). Бот работает с той же базой.

## 1. Создать бота

1. В @BotFather: `/newbot` → имя (например, `PULLUP PRO`) → username, оканчивающийся на `bot`.
2. Скопируйте токен. Он секретный: храните только в `.env` на сервере, не коммитьте и не отправляйте в чаты.
3. Необязательно: `/setuserpic` — аватар бота (можно взять `apps/web/public/icons/icon-512.png`).

Команды, описание и кнопку меню бот устанавливает сам при старте (`BOT_SETUP_PROFILE=true`): команды на русском и английском, короткое описание, описание и кнопка меню «PULLUP PRO» со ссылкой на `WEBAPP_URL` (только если адрес начинается с `https://`).

## 2. Настроить переменные окружения

```dotenv
BOT_TOKEN=<токен от BotFather>
BOT_USERNAME=<username бота без @>      # включает «Войти через Telegram» в браузере и PWA
WEBAPP_URL=https://fit.example.com/     # адрес приложения
BOT_MODE=polling                        # или webhook
```

`BOT_TOKEN` нужен обоим сервисам: API проверяет им подпись `initData`, бот — работает с Bot API. Остальные параметры — в `.env.example`.

## 3. Подключить Mini App

Вариант А — кнопка меню (делает бот автоматически при старте). Вручную: @BotFather → `/mybots` → бот → **Bot Settings → Menu Button** → URL `WEBAPP_URL`.

Вариант Б — основной Mini App профиля бота: @BotFather → `/mybots` → бот → **Bot Settings → Configure Mini App** → **Enable Mini App** → URL `WEBAPP_URL`. Появится кнопка «Открыть» в профиле бота и ссылка `https://t.me/<bot>?startapp`.

Вариант В — отдельная ссылка: `/newapp` → выбрать бота → название, описание, картинка 640×360 → URL → короткое имя. Ссылка вида `https://t.me/<bot>/<app>`.

Бот также отправляет кнопку «ОТКРЫТЬ PULLUP PRO» в ответ на `/start`.

## 4. Запустить бота

```bash
npm run build -w @pullup/telegram-bot
npm run start:bot          # или: docker compose --profile bot up -d --build
```

В логе: `authorized as @<username>`. Если `BOT_USERNAME` не задан, бот подскажет значение для API.

### Polling или webhook

| | polling (по умолчанию) | webhook |
|---|---|---|
| Публичный адрес для бота | не нужен | нужен HTTPS |
| Настройка | ничего | `BOT_MODE=webhook`, `WEBHOOK_URL=https://fit.example.com/tg-webhook`, `WEBHOOK_SECRET=<16–256 символов>` |
| Как работает | бот сам забирает обновления; при старте удаляет webhook | бот слушает `BOT_PORT` (8081) и путь из `WEBHOOK_URL`, проверяет заголовок секрета, регистрирует webhook при старте; `GET /health` для проверки |
| Экземпляров | ровно один (иначе Telegram вернёт 409) | один экземпляр бота на токен |

`deploy/Caddyfile` уже проксирует `/tg-webhook*` на бота, остальное — на API.

## Как работает вход

- **Внутри Telegram**: Mini App отправляет `initData` в `POST /api/auth/telegram`; API проверяет подпись HMAC-SHA-256 токеном бота и возраст данных (`INITDATA_MAX_AGE`, по умолчанию 24 часа). Вход происходит автоматически.
- **В браузере и PWA**: «Войти через Telegram» → одноразовая ссылка `t.me/<bot>?start=link_<код>` (действует 10 минут) → в боте «Включить синхронизацию?» → подтвердить → приложение входит само.
- Данные синхронизируются между Mini App, PWA и браузером одного пользователя Telegram.

## Возможности внутри Telegram

- Тема «Системная» повторяет цветовую схему Telegram; по умолчанию — фирменная тёмная тема PULLUP PRO.
- Учитываются безопасные зоны (`safeAreaInset`, `contentSafeAreaInset`); при включённой настройке «Тренировка на весь экран» тренировка на телефоне открывается в полноэкранном режиме Telegram (Bot API 8.0+).
- BackButton Telegram работает как «Назад»; MainButton повторяет главное действие экрана («НАЧАТЬ ТРЕНИРОВКУ») и скрывается, пока открыт диалог или идёт тренировка.
- Во время тренировки включено подтверждение закрытия, чтобы не потерять подходы случайным свайпом.
- Глубокие ссылки: `?screen=<экран>` в URL Mini App или параметр запуска `startapp` / `start_param`. Экраны: `home`, `train`, `plan`, `stats`, `body`, `nutrition`, `settings`, `report`, `profile`, `mu`, `achievements`, `journal`. Пример: `https://t.me/<bot>/<app>?startapp=stats`.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и кнопка «ОТКРЫТЬ PULLUP PRO»; `/start link_<код>` — подтверждение входа из браузера |
| `/today` | Миссия дня и следующая тренировка с дозировками |
| `/stats` | Реальные итоги: тренировки, подходы, повторения, неделя |
| `/progress` | Изменения силы и совет по правилам |
| `/reminder`, `/reminders` | Список напоминаний, включение и выключение кнопкой |
| `/settings` | Текущие настройки и ссылка в приложение |
| `/help` | Справка |

Без синхронизированных данных бот объясняет, как включить синхронизацию, и не показывает выдуманные цифры. В группах бот не выводит личные данные.

## Напоминания

Настраиваются в приложении (Настройки → Напоминания): тренировка, вес, вода, мобилити; время и дни недели. После синхронизации бот присылает их в Telegram по локальному времени пользователя (часовой пояс профиля или `DEFAULT_TZ`) — одно сообщение в день на напоминание; напоминание о тренировке не приходит, если тренировка уже сделана. Если пользователь заблокировал бота, напоминания ставятся на паузу. Отключить в боте — `REMINDERS=false`.

## Проверено и не проверено

- Проверено автотестами: подпись `initData` (в том числе по независимой реализации алгоритма), отказ для поддельных/изменённых/просроченных данных, команды и тексты бота через настоящий grammY с записанными ответами Bot API, напоминания, вход из браузера через бота, синхронизация Mini App → сервер → бот, поведение Mini App с тестовым двойником Telegram SDK (BackButton, MainButton, тема, safe area, deep link).
- **Не проверено** в этой работе: настоящий токен бота, реальное приложение Telegram на iOS/Android/Desktop, регистрация webhook на реальном домене. Перед запуском выполните проверку по шагам выше на своём боте.
