# PWA: установка, офлайн и обновления

PULLUP PRO устанавливается как приложение на телефон и компьютер, запускается без адресной строки и работает без интернета. Сервер для этого не нужен — достаточно раздать собранную папку `apps/web/dist` по HTTPS.

## Требования

- **HTTPS** (или `http://localhost` при разработке): без него браузер не регистрирует service worker и не предлагает установку.
- Раздача из корня домена или из подкаталога: все пути относительные (`./`), `scope` и `start_url` манифеста — `./`.
- Сервер не должен кэшировать `index.html`, `sw.js`, `version.json` и `manifest.webmanifest` (API PULLUP PRO отдаёт их с `Cache-Control: no-cache`; при раздаче другим сервером настройте так же). Файлы в `assets/` имеют хеш в имени и могут кэшироваться надолго.
- MIME `application/manifest+json` для `.webmanifest` желателен (большинство серверов отдают его сами).

## Что входит в сборку

```bash
npm run build:web       # → apps/web/dist
npm run preview         # проверка сборки на http://localhost:4173
```

| Файл | Назначение |
|---|---|
| `manifest.webmanifest` | Имя «PULLUP PRO — ISA Personal Fitness», `display: standalone`, тёмная тема `#09090b`, иконки 192/512 (`any` и `maskable`), ярлыки: Тренировка, План, Статистика, Тело |
| `icons/*` | Готовые иконки в `apps/web/public/icons` (192, 512, maskable 192/512, apple-touch-icon, favicon 32 и SVG, ярлык 96). Перегенерация из векторного знака: `npm i --no-save sharp && node scripts/icons.mjs` |
| `sw.js` | Генерируется плагином в `apps/web/vite.config.ts` из `apps/web/sw/sw-template.js`: список кэширования — все файлы сборки, версия — `2.0.0-<хеш файлов сборки и шаблона service worker>` |
| `version.json` | Версия, число файлов и время сборки (для диагностики) |

`index.html` содержит `theme-color`, `apple-mobile-web-app-*` и `apple-touch-icon` для iOS.

## Как работает офлайн

- При установке service worker кэширует оболочку приложения (HTML, JS, CSS, манифест, иконки) в кэш `pullup-pro-shell-<версия>`.
- Навигации внутри приложения получают закэшированный `index.html` текущей версии; статика — из кэша, затем из сети.
- Запросы `/api/*` и сторонние запросы **никогда** не кэшируются; данные пользователя (localStorage, IndexedDB) service worker не трогает.
- Все функции приложения работают офлайн: тренировки, журнал, статистика, тело, питание, календарь, резервные копии. При отсутствии сети показывается значок «Офлайн», изменения синхронизации копятся и отправляются автоматически при возвращении связи.
- Приложение запрашивает у браузера постоянное хранилище (`navigator.storage.persist()`), чтобы данные и фото не удалялись при нехватке места.

## Обновления

1. Новая версия публикуется (новая сборка `dist`).
2. Открытое приложение проверяет обновление каждый час и при возвращении на вкладку (кнопка «Проверить обновления» есть в настройках).
3. Новый service worker устанавливается в фоне и **ждёт**: пользователь видит панель «Доступна новая версия PULLUP PRO. Данные сохранятся.» — активная тренировка не прерывается.
4. По кнопке «Обновить» новая версия активируется (`SKIP_WAITING`), страница перезагружается, удаляются только старые кэши `pullup-pro-*`. Данные пользователя не затрагиваются.

## Установка пользователем

| Платформа | Как установить |
|---|---|
| Android (Chrome, Edge, Samsung Internet) | Баннер «Установить» на главном экране приложения (событие `beforeinstallprompt`) или меню браузера → «Установить приложение» |
| Windows, macOS, Linux (Chrome, Edge) | Значок установки в адресной строке или баннер в приложении |
| iPhone, iPad (Safari) | «Поделиться» → «На экран „Домой“» → «Добавить». Приложение показывает эту инструкцию само, потому что iOS не поддерживает `beforeinstallprompt` |
| Telegram Mini App | Установка не предлагается: приложение открывается внутри Telegram |

Баннер установки можно закрыть; после установки он больше не показывается.

## Проверка

- Автотесты `tests/e2e/pwa.spec.ts`: манифест и размеры иконок, баннер установки, холодный старт без сети с ответом из service worker и сохранением данных, обновление версии с сохранением данных. См. [TESTING.md](TESTING.md).
- Вручную: Chrome DevTools → Application → Manifest / Service Workers / Cache Storage; вкладка Network → Offline.

## Ограничения

- Установка и офлайн-режим проверены в Chromium (автотесты). На реальных iOS/Android-устройствах в рамках этой работы не проверялись.
- Safari может удалить данные сайта, если приложением долго не пользоваться и оно не установлено на экран «Домой»; для надёжности используйте синхронизацию или резервную копию JSON (Настройки → Данные).
