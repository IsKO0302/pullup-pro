| Сборка web + API + бот | `npm run build` | успешно |

Локальный PostgreSQL без установки (Windows): `npm i embedded-postgres` в отдельной папке, запустить кластер на порту 54329 и создать базы `CREATE DATABASE pullup_test ENCODING 'UTF8' TEMPLATE template0 LC_COLLATE 'C' LC_CTYPE 'C'` (кластер по умолчанию создаётся в WIN1251).

Скриншоты: `docs/screenshots/` (индекс — `README.md`), перегенерация — `npm run dev`, затем `node tests/qa/gallery.mjs http://localhost:5173/ docs/screenshots`.
## Подготовка

```bash
npm ci
npx playwright install chromium        # или свой браузер: CHROMIUM_PATH=/usr/bin/chromium
createdb pullup_test                   # для интеграционных тестов
createdb pullup_e2e                    # для e2e
```

Обе тестовые базы **полностью очищаются** тестами (e2e пересоздаёт схему `public`) — не указывайте рабочую базу.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TEST_DATABASE_URL` | — | База интеграционных тестов. Без неё интеграционные тесты пропускаются с предупреждением |
| `E2E_DATABASE_URL` | `postgres://postgres@127.0.0.1:5432/pullup_e2e` | База e2e |
| `CHROMIUM_PATH` | браузер Playwright | Свой Chromium |

## Команды

```bash
npm run typecheck
npm run test:unit
TEST_DATABASE_URL=postgres://postgres@127.0.0.1:5432/pullup_test npm run test:integration
npm run test:e2e          # сначала собирает web и API (pretest:e2e)
npm run test:all          # typecheck + unit + integration + e2e
npx playwright test tests/e2e/pwa.spec.ts --reporter=line   # один файл
```

### E2E (`tests/e2e`, Playwright + Chromium)

`tests/e2e/server.mjs` копирует собранный `apps/web/dist` во временный каталог, очищает базу e2e и запускает собранный API (порт 4310), который раздаёт клиент. Telegram SDK заменяется тестовым двойником `telegram-stub.js` (журнал вызовов, BackButton, MainButton, события темы); `initData` подписывается тестовым токеном по алгоритму Telegram.

| Файл | Тестов | Сценарии |
|---|---|---|
| `onboarding.spec.ts` | 2 | Первый запуск и персонализация создают профиль и план; навигация по всем разделам |
| `workout.spec.ts` | 2 | Выбор программы, подходы, таймер отдыха, пауза и продолжение, восстановление после перезагрузки, сохранение и статистика; конструктор: создать, сохранить, запустить свою тренировку |
| `data.spec.ts` | 5 | Тело: замеры, валидация, вес; экспорт JSON → сброс → импорт восстанавливает всё; битый файл отклоняется без изменения данных; импорт настоящей копии 1.0 (журнал, статистика, календарь, достижения); календарь и автоплан на 4 недели |
| `pwa.spec.ts` | 4 | Манифест и иконки; баннер установки; холодный старт офлайн из service worker с сохранением; обновление: новая версия ждёт, предлагается, применяется по кнопке, данные сохраняются, остаётся только новый кэш |
| `telegram.spec.ts` | 5 | Mini App: запуск, глубокая ссылка, safe area, BackButton, MainButton, автоматический вход; тема «Системная» следует Telegram; поддельные/изменённые/просроченные `initData` отклоняются; синхронизация Mini App → сервер → бот (настоящий grammY), вход второго устройства через бота, офлайн-изменение и отправка при восстановлении сети; телефон 390 px без горизонтальной прокрутки |
| `responsive.spec.ts` | 8 | 19 экранов на ширинах 320, 360, 390, 430, 768, 1024, 1366, 1920 px: нет горизонтальной прокрутки, ни один элемент не выходит за экран, за свою карточку, плитку или подсказку; текст подсказки не сжимается кнопкой; значения KPI не обрезаются многоточием; нет `NaN` / `undefined` в тексте |
| `single-file.spec.ts` | 1 | Версия в одном файле открывается с диска (`file://`): первый запуск с демо-данными, 9 разделов, пояснения в настройках, service worker не регистрируется, ни одного запроса за пределы файла, данные сохраняются после повторного открытия |

### Ручная проверка (`tests/qa`)

Скрипты скриншотов для визуальной проверки: `screens.mjs <папка>` (30 снимков из версии в одном файле: первый запуск, разделы, тренировка от проверки самочувствия до итогов — телефон 390 px; основные разделы — компьютер 1440 px; падает при ошибках в консоли), `pages.mjs` (набор экранов с демо-данными или пустым состоянием), `workout.mjs` (экраны тренировки), `shot.mjs` (один URL). Браузер — из Playwright или `CHROMIUM_PATH`.

## Что не покрыто

- Настоящий Telegram: реальный токен бота, клиенты Telegram на iOS/Android/Desktop, регистрация webhook на домене.
- Реальные устройства и браузеры кроме Chromium (Safari/iOS, Firefox, Android WebView).
- `docker build`, docker-compose, Caddy и выпуск сертификатов (Docker недоступен в среде проверки; раскладка образа проверена вручную, см. [DEPLOYMENT.md](DEPLOYMENT.md)).
- Нагрузочное тестирование.
