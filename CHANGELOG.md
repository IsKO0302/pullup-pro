## [2.0.0] — PULLUP PRO 2.0

### Добавлено

- **Персонализация** из 7 шагов (старт, профиль, результаты, оборудование, режим, цели, план) и рекомендация уровня Beginner / Intermediate / Advanced / Elite.
- **Каталог**: 85 упражнений (подтягивания и тяги, жимы и отжимания, корпус, плечи, выход силой, ноги, мобилити), 8 групп, 23 мышцы, карта мышц, техника, ошибки, прогрессии «легче / сложнее».
- **Движок тренировок 2.0**: 7 программ (Full Body A/B/C, Push/Pull/Legs, Upper/Lower, спина и бицепс, грудь и плечи, корпус, подготовка к выходу силой) поверх 3 программ подтягиваний 1.0; подбор упражнений под оборудование, разминка, дозы по уровню, RIR/RPE, предложение прогрессии только с подтверждением, кнопка «Боль» снижает нагрузку, лёгкая тренировка после тяжёлой, разгрузочная неделя.
- **Режим тренировки**: таймер отдыха со звуком, пауза и продолжение, восстановление после перезагрузки или закрытия, замена упражнения, полноэкранный режим, итоги и рекорды.
- **Тело**: вес, замеры, свои поля, фото прогресса (спереди, сбоку, сзади) с локальным хранением и облаком только по отдельному согласию.
- **Питание**: приёмы пищи, свои продукты, калории и БЖУ, вода, ориентиры белка по весу.
- **План и календарь**: планирование тренировок, автоплан на 4 недели, отметки выполнения.
- **Недельный отчёт**, расширенная статистика по периодам, 16 новых достижений (всего 52), миссия дня, советы по правилам.
- **PWA**: манифест, иконки (включая maskable и Apple), установка (баннер и инструкция для iOS), офлайн-оболочка, обновления по подтверждению без потери данных и без прерывания тренировки, постоянное хранилище.
- **Telegram Mini App**: автоматический вход, тема Telegram, safe area, BackButton, MainButton, подтверждение закрытия во время тренировки, глубокие ссылки на экраны.
- **Сервер**: API (Fastify) с проверкой подписи Telegram `initData`, сессиями, синхронизацией между устройствами (last-writer-wins, офлайн-очередь), фото с согласием, экспортом и удалением аккаунта, CSP и rate limit; PostgreSQL с миграциями и SQL-представлениями сущностей.
- **Telegram-бот** (grammY): `/start`, `/today`, `/stats`, `/progress`, `/reminder`, `/settings`, `/help`, вход в браузере через бота, напоминания о тренировке, весе, воде и мобилити по локальному времени; режимы polling и webhook.
- **Темы** «Тёмная» (по умолчанию), «Светлая», «Системная».
- **Снимки безопасности** перед импортом, сбросом, демо-данными и восстановлением, с откатом в настройках.
- **Развёртывание**: Dockerfile (цели api и bot), docker-compose (PostgreSQL, API, бот, Caddy с HTTPS), `.env.example`.
- **Версия в одном файле**: `npm run build:single` → `dist-single/PULLUP-PRO-2.0.0.html` — открывается двойным щелчком без сервера и интернета; данные в этом браузере, перенос через экспорт и импорт JSON.
- **Тесты**: юнит, интеграционные на PostgreSQL, e2e в Chromium (персонализация, тренировка, данные, PWA, Telegram, адаптивность, версия в одном файле). **Документация** в `docs/`.

### Изменено

- Код 1.0 из глобальных скриптов переведён в монорепозиторий TypeScript (npm workspaces: `packages/shared`, `packages/db`, `apps/web`, `apps/api`, `apps/telegram-bot`), сборка Vite и esbuild.
- Хранение: `localStorage` `pullup.pro.v2` + зеркало в IndexedDB, отдельный ключ активной тренировки, фото в IndexedDB.
- 36 упражнений 1.0 сохранили id и дополнены техникой, ошибками и дозами.

### Перенос данных

- Данные 1.0 (`pullup.pro.v1`) переносятся автоматически при первом запуске и при импорте резервной копии 1.0; исходные данные 1.0 не изменяются. Подробности — [docs/AUDIT.md](docs/AUDIT.md).

### Исправлено

- Перезагрузка при первой активации service worker и надёжная перезагрузка после «Обновить».
- Значок «Офлайн» на широких экранах с боковым меню.
- Горизонтальная прокрутка на ширине 1024 px в библиотеке упражнений.
- Кнопка в карточке питания (390 px) и значки карточек программ (320 px) выходили за край карточки; обрезанное значение «Время» в статистике на телефоне.
- Версия кэша service worker учитывает изменения самого service worker.
- Значение «Время» в статистике обрезалось и на компьютере (1366–1440 px) — теперь переносится на вторую строку.
- Отчёт недели (390 px): значок «цель выполнена» сжимался, и подпись вылезала за рамку — теперь отдельной строкой под именем.
- Настройки (телефон): текст о демо-данных сжимался кнопкой «Вернуть мои данные» до одного слова в строке — кнопка переносится под текст.
- `index.html` сборки для хостинга, открытый с диска, показывал страницу без оформления — добавлена версия в одном файле и пояснение в README.

### Известные ограничения

- Не проверены в этой работе: настоящий токен бота и реальное приложение Telegram, развёртывание на домене с HTTPS, `docker build` и Caddy, реальные iOS/Android-устройства.
- Синхронизация разрешает конфликты по времени изменения на устройстве (last-writer-wins): при одновременном редактировании одной записи на двух устройствах с неверными часами может победить не та версия.
